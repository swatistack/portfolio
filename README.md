# Swati Chauhan Portfolio

Static portfolio website for Swati Chauhan, Laravel Developer.

## Files

- `index.html` - portfolio page content
- `styles.css` - responsive visual design
- `script.js` - scroll reveal animation
- `assets/swati-chauhan-cv.pdf` - downloadable resume

## Publish On GitHub Pages

1. Create a GitHub repository, for example `swati-portfolio`.
2. Upload these files to the repository root.
3. Go to repository `Settings` > `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.

Your portfolio link will look like:

```text
https://YOUR-GITHUB-USERNAME.github.io/swati-portfolio/
```

Use that link in your resume and LinkedIn profile.
